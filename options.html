ThunderCat 6.0

Dynamische Sortierung nach Kategorie und Absenderdomain

Automatik

KI-Provider

Für den automatischen ChatGPT-Modus wird die OpenAI API verwendet. ChatGPT-Abonnement und API-Abrechnung sind getrennt.

API-Keys werden lokal im Thunderbird-Erweiterungsspeicher abgelegt. Der vollständige Nachrichtentext wird nicht an die KI gesendet; verwendet werden Absender, Domain und bis zu fünf Betreffzeilen.

Konten

Wenn kein Konto ausgewählt ist, verarbeitet ThunderCat alle Mailkonten.

Ordnerstruktur

INBOX/
├─ Arbeit/<domain>
├─ Finanzen/<domain>
├─ Shopping/<domain>
├─ Webhosting/<domain>
├─ Newsletter/<domain>
├─ Privat/<domain>
└─ Sonstiges/<domain>

Gelernte Absender

Eine Zuordnung wird pro Absender gespeichert. Dadurch muss eine bekannte Adresse nicht erneut per KI analysiert werden.

Kontextmenü

Rechtsklick auf eine Nachricht → ThunderCat → „Zu Arbeit lernen“, „Zu Finanzen lernen“, „Zu Digitales lernen“ usw. Die Zuordnung wird gespeichert und die ausgewählte Nachricht sofort in den passenden Domain-Unterordner verschoben.
